# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

All `dotnet` commands must be run from the `./src` directory.

```bash
dotnet restore
dotnet build --no-restore -warnaserror
dotnet format --verify-no-changes          # check code style (CI enforces this)
dotnet format                              # auto-fix code style
dotnet test --no-build --verbosity normal  # run tests
dotnet pack --configuration Release -p:Version=<version> --output .
```

CI additionally passes `-p:AssemblyVersion` (pinned to the major) and `-p:FileVersion`; see `.github/workflows/publish-nuget.yml`.

## Architecture

This is a **JSON serialization library** for PureQL query models. It depends on `PureQL.CSharp.Model` (which mirrors PureQL specification `0.1.0-preview.1.0.0`; see its CLAUDE.md for the naming rules) and adds `System.Text.Json` support on top.

**Entry point:** `PureQLConverters` — a `sealed record` that implements `IEnumerable<JsonConverter>` and yields one `PureQLConverter<T>` per model type. Consumers register all converters into a `JsonSerializerOptions` instance in a single loop.

**Engine (project root, hand-written):** `ModelRegistry` holds a `ModelDescriptor` per model type and is built once. A converter buffers the value as a `JsonDocument` and asks the registry to read it.
- `RecordDescriptor` — a record as one JSON object, read through `ObjectReader` (tracks read properties, so any other one is rejected) and written through `ObjectWriter` (omits schema defaults).
- `UnionDescriptor` — a OneOf union whose cases accept disjoint *signatures* (`Discriminators.Of`: the `operator`, `round(digits)`, or a leaf kind plus type such as `field decimal?`). The dispatch table is computed when the registry is built and throws on ambiguity.
- `ProbeUnionDescriptor` — `Equal*`, `NotEqual*`, `In*`, comparisons and `Value*` unions, chosen by the `TypeFamily` that `Discriminators.Probe` reports for the operand (mirrors `probe.*` in the schema).
- `PresenceUnionDescriptor` — query forms by `groupBy`, `From` / `Join` by `subquery`.
- `Literals/LiteralValues` — literal formats checked against the schema patterns; values the CLR type cannot hold exactly are rejected.

**Registrations:** `QueryRegistrations` (root types) is hand-written. The other `*Registrations` classes, in folders mirroring the model namespaces (`Fields/`, `Parameters/`, `Literals/`, `Keys/`, `Lists/`, `RowExpressions/`, `ProjectionExpressions/`, `GroupExpressions/`, `GroupKeys/`, `SelectItems/`), were generated by a one-off script that reflects over the model and reads the schema: one registration per model type, operator names and fixed `over` values from the schema, JSON property names equal to constructor parameter names. Apply small model changes by hand in the same shape.

**Test project:** `PureQL.CSharp.Model.Serialization.Tests` targets `net10.0` and uses xunit. `Specification/` holds `samples/`, `valid/` and `invalid/` (the fixtures of `samples/`, `tests/valid/` and `tests/invalid/`) and the schema of specification `0.1.0-preview.1.0.0`, copied unchanged. Valid fixtures must round-trip to semantically equal JSON (`JsonSemantics`); invalid ones must fail, except those listed in `InvalidQueryTests.AcceptedByModel` (constraints the model cannot express). `ProbeParityTests` checks `Discriminators.Probe` against the schema's `probe.*`. `ModelRoundTripTests` builds every variant of every model type by reflection and checks it reads back as the same variant.

**Multi-targeting:** net7.0, net8.0, net9.0, net10.0. `IsAotCompatible` is `true` for net8.0 and later (the analyzers do not support net7.0); no reflection or `JsonSerializer` calls inside converters.

**Publishing:** triggered by pushing a semver tag (pattern `*.*.*`). The tag becomes the `PackageVersion`. The workflow publishes to both GitHub Packages and NuGet.org.

## Code Style

Enforced via `.editorconfig` and `dotnet format --verify-no-changes` in CI:

- No `var` — always use explicit types
- No expression-bodied methods or constructors — use block bodies
- Expression-bodied properties and accessors are required
- File-scoped namespace declarations (`namespace Foo.Bar;`)
- Private fields prefixed with `_` in camelCase (e.g., `_options`)
- Braces always required, even for single-statement blocks
- Max line length: 90 characters
- Allman brace style — opening brace on its own line for all blocks
- `System.*` using directives sorted first, no blank line between using groups
- Parentheses required in arithmetic and relational binary operators for clarity
